Plano completo e 100% open source para o Colab: baixar o vídeo com **yt-dlp** (+ **aria2** para acelerar), extrair áudio com **ffmpeg**, transcrever qualquer idioma com **faster-whisper**, traduzir as legendas para português e gravá-las no vídeo.

**Atenção:** o Whisper só traduz para **inglês** (`task="translate"`). Para sair **qualquer idioma → português**, o caminho é: transcrever no idioma original → traduzir o texto das legendas com `deep-translator`/`googletrans` → gravar no vídeo.

### Pipeline

```python
# 1) Baixar o vídeo (com aria2 como acelerador)
!yt-dlp -f "bv*+ba/b" --downloader aria2c -o "video.%(ext)s" "URL_DO_VIDEO"

# 2) Transcrição no idioma original (detecta sozinho)
from faster_whisper import WhisperModel
model = WhisperModel("large-v3", device="cuda", compute_type="float16")
segments, info = model.transcribe("video.mp4", vad_filter=True)

# 3) Gera .srt e traduz para português
from deep_translator import GoogleTranslator
tr = GoogleTranslator(source="auto", target="pt")
# (iterar os segmentos → traduzir cada linha → escrever o .srt)

# 4) Gravar as legendas no vídeo (hardcode)
!ffmpeg -i video.mp4 -vf "subtitles=video_pt.srt" -c:a copy video_legenda.mp4
```
